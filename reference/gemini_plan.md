針對 SMT 產線極少樣本與微細瑕疵檢測之次世代工業異常檢測架構深度研究報告1. 執行摘要與現況診斷 (Executive Summary & Diagnosis)1.1 核心問題情境分析本報告針對 貴公司目前在表面貼裝技術（Surface Mount Technology, SMT）產線面臨的嚴峻檢測挑戰進行深入剖析與解決方案規劃。當前的生產環境具有高度的技術矛盾性：一方面要求極高的檢測標準（0 漏失、低於 10% 的過殺率、80% 直通率），另一方面卻受限於極端的數據匱乏（缺乏真實 NG 樣本，OK 樣本僅 10~20 張）。現行採用的技術堆疊——基於 FastFlow 演算法配合 DINOv3 骨幹網路（Backbone），並針對每個零件腳位獨立訓練——雖然代表了當前無監督異常檢測（Unsupervised Anomaly Detection, UAD）的主流方向，但在面對 SMT 特有的「微細瑕疵」與「邏輯瑕疵」時，顯現出架構性的極限。這並非單純的模型參數調整問題，而是演算法的歸納偏置（Inductive Bias）與實際物理瑕疵特徵之間的不匹配所致。1.2 現行架構失效之根本原因分析 (Root Cause Analysis)透過對現有技術架構與 SMT 檢測需求的深度解構，分析指出三大核心失效原因：FastFlow 的解析度瓶頸與特徵平滑化（Resolution Bottleneck & Smoothing）：FastFlow 利用二維正規化流（2D Normalizing Flows）來估計特徵的機率密度，理論上能保留空間資訊。然而，DINOv3 作為 Vision Transformer (ViT) 架構，其輸出的特徵圖（Feature Map）是基於 Patch（通常為 $14 \times 14$ 像素）的嵌入向量。對於 SMT 焊點上的微小氣孔、細微刮痕或 0.1mm 等級的連錫（Solder Bridge），這些特徵在經過 ViT 的層層編碼後，往往被周圍的正常紋理特徵「平均化」或「平滑化」。正規化流模型傾向於學習全域的分布規律，對於局部高頻的微小變異（High-frequency local variations）敏感度不足，導致小瑕疵無法在機率密度圖上形成顯著的異常峰值 1。語義邏輯的缺失（The Semantic Gap in Logical Anomalies）：DINOv3 雖然具備強大的語義提取能力，但 FastFlow 本質上是將影像視為紋理分佈（Texture Distribution）。它無法理解組件之間的「關係」與「邏輯」。例如，一顆電容本身紋理是正常的，但如果它被旋轉了 90 度（極性錯誤）或被錯誤地貼裝在空焊盤上（錯件），對於基於分佈的模型來說，這些像素點仍在「正常紋理」的流形（Manifold）範圍內。這類瑕疵屬於「分佈內但結構錯誤」（In-distribution but structurally invalid），是純機率密度估計方法的盲點 4。極少樣本下的訓練不穩定性（Instability in Few-Shot Regime）：僅使用 10~20 張 OK 影像進行訓練，導致模型學習到的正常流形邊界極度不穩定。這種「冷啟動」（Cold Start）問題使得模型在推論時，對於稍有光影變化的正常樣本容易誤判為異常（過殺），或者為了降低過殺而放寬邊界，導致漏失。缺乏真實 NG 樣本（Hard Negatives）作為邊界約束，使得決策邊界處於「真空」狀態，下游任務模型無法收斂至穩健狀態 7。1.3 策略建議總覽為達成 0 漏失目標並解決雙重瑕疵屬性（結構性與邏輯性），本報告提出 「混合式邏輯-結構檢測系統」（Hybrid Logic-Structural Inspection System, HLSIS）。該系統將不再依賴單一的異常檢測頭，而是採取分流策略：結構流（Structural Stream）： 採用 SimpleNet 或 EfficientAD 架構，專注於特徵辨別而非密度估計，以解決微小瑕疵抓取問題。邏輯流（Logical Stream）： 引入 SALAD 架構的組件感知分支，專門處理缺件、錯件、極性反轉等邏輯問題。數據引擎（Data Engine）： 利用貴公司擁有的 300 萬張工業數據進行 領域自適應預訓練（Domain-Adaptive Pretraining, DAPT），並建立基於 Stable Diffusion 的生成式數據增強管道，以合成高品質的 NG 樣本來穩定模型訓練。2. 2024-2025 工業異常檢測前沿技術深度探討 (State-of-the-Art Review)本章節詳盡梳理針對小瑕疵檢測、邏輯異常識別及極少樣本學習的最新學術進展，為新架構設計提供理論支撐。2.1 針對微細瑕疵的特徵辨別技術SMT 製程中的微短路（Micro-shorting）、少錫（Insufficient Solder）或元件裂紋（Cracks）屬於極高頻的視覺特徵。傳統的 Flow-based 方法（如 FastFlow, C-Flow）在處理這類特徵時往往因降維或密度估計而丟失細節。2.1.1 SimpleNet: 特徵空間的噪聲合成 (CVPR 2023/2024)SimpleNet 9 提出了一種反直覺但極為有效的策略。它不構建複雜的生成網路或流模型，而是凍結預訓練骨幹網路，並訓練一個輕量級的「特徵適配器」（Feature Adapter）。核心機制： SimpleNet 在特徵空間（Feature Space）中向正常樣本的特徵向量添加高斯噪聲（Gaussian Noise），人為地合成「異常特徵」。接著，訓練一個鑑別器（Discriminator）來區分「真實正常特徵」與「合成異常特徵」。優勢： 這種方法直接在特徵維度上劃分決策邊界，對於微小的特徵偏移（即小瑕疵）極為敏感。由於不需要進行影像重建，其推論速度極快（在 RTX 3080Ti 上可達 77 FPS），且在高解析度特徵圖上運作良好，避免了 Resize 帶來的資訊丟失。針對 SMT 的適用性： 對於連錫或微裂紋，這些瑕疵在特徵空間表現為偏離正常簇的向量。SimpleNet 透過合成噪聲強迫模型收緊正常邊界，能有效抓出這些離群點。2.1.2 EfficientAD: 毫秒級延遲與硬特徵損失 (CVPR 2024)EfficientAD 11 專為即時工業檢測設計。核心機制： 它屏棄了通用的 ResNet/ViT，改用專門設計的 Patch Description Network (PDN)。這是一個輕量級 CNN，專注於提取高細節的局部特徵。架構上採用學生-教師（Student-Teacher）蒸餾模式，但在訓練中引入了 「硬特徵損失」（Hard Feature Loss），強迫學生網路專注於那些難以重建的異常特徵。邏輯異常檢測模組： EfficientAD 引入了一個自編碼器（Autoencoder）來檢測全域異常，並透過學生網路與自編碼器輸出的差異來識別邏輯錯誤。優勢： 推論時間小於 2ms，且對局部紋理變異（如焊點光澤變化）具有很好的魯棒性。2.1.3 Reverse Distillation with Reconstruction Enhancement (RD-RE)RD-RE 13 解決了傳統重建模型（如 Autoencoder）的「特徵洩漏」問題，即模型「太聰明」，以至於能完美重建出異常區域，導致異常檢測失敗。核心機制： 採用反向蒸餾架構（教師編碼器 -> 學生解碼器），強迫學生網路只能從教師網路的高層語義特徵中還原底層細節。由於高層特徵不包含異常的細節資訊，學生網路無法重建出異常，從而產生巨大的重建誤差，精準定位瑕疵。2.2 邏輯異常檢測的突破性進展 (Logical Anomaly Detection)SMT 產線的「特殊邏輯瑕疵」（如元件極性反轉、錯件、缺件）是傳統 UAD 的死穴。這類瑕疵在像素層面是正常的，但在語義層面是錯誤的。2.2.1 SALAD: 語義感知的邏輯異常檢測 (ICCV 2025)SALAD (Semantics-Aware Logical Anomaly Detection) 5 是目前解決邏輯異常的最先進方法（SOTA）。核心創新： 它在傳統的紋理檢測分支之外，新增了一個 「組件分支」（Composition Branch）。這個分支不看紋理，而是預測影像的「組件分割圖」（Composition Map）。它學習的是組件的類別、位置與排列關係的聯合分佈。運作原理： 模型會生成一個代表組件佈局的特徵圖。如果一個電容缺件，該位置的組件特徵就會缺失；如果錯件，該位置的類別特徵就會不匹配。SALAD 明確地對組件佈局進行建模，在 MVTec LOCO（邏輯異常資料集）上達到了 96.1% 的 AUROC。針對 SMT 的適用性： 這是解決貴公司「特殊邏輯瑕疵抓不太到」的關鍵鑰匙。SMT 本質上就是組件的排列組合，SALAD 的架構完美契合此需求。2.2.2 LogicAD: 基於視覺語言模型的解釋性檢測LogicAD 14 利用大型視覺語言模型（VLM）提取圖像的文字描述，並結合自動定理證明器（Automated Theorem Prover）進行邏輯推理。例如，它可以驗證「圖像中必須包含 3 個電阻，且排列成一直線」這樣的規則。雖然精確度極高且具備可解釋性，但其推論延遲較高，可能不適合高速 SMT 線，除非進行模型蒸餾。2.3 極少樣本學習與生成式增強 (Few-Shot & Generative AI)面對僅有 10-20 張 OK 照片且無 NG 照片的困境，純粹的訓練是不夠的，必須依靠「先驗知識」與「合成數據」。2.3.1 RegAD: 基於配準的少樣本檢測 (ECCV 2022)RegAD 16 針對類別無關（Category-agnostic）的少樣本檢測。核心機制： 它在比對特徵之前，先進行「配準」（Registration），即將測試影像透過空間變換網路（STN）對齊到 Support Set（那幾張 OK 圖）的標準姿態。優勢： 這消除了 SMT 元件因貼裝誤差產生的微小位移或旋轉帶來的誤報，使得模型可以進行非常嚴格的像素級比對，大幅提升少樣本下的檢測能力。2.3.2 DefectFill 與 RealNet: 生成式異常合成DefectFill 18 與 RealNet 19 利用擴散模型（Diffusion Models）來解決無 NG 數據的問題。核心機制： 它們使用 Stable Diffusion 結合 Inpainting 技術，在正常影像上「畫」出逼真的瑕疵。不同於簡單的 CutPaste（剪貼），擴散模型生成的瑕疵（如裂紋、髒汙）能順應物體的幾何結構與光影，產生極具挑戰性的「硬負樣本」（Hard Negatives）。應用： 這能讓您在沒有真實 NG 照片的情況下，訓練出具備高鑑別力的監督式或半監督式模型。3. 開發新模型規格與規劃 (New Model Spec & Planning)基於上述研究，現有的 FastFlow 單一架構無法同時滿足微細結構瑕疵與高層邏輯瑕疵的檢測需求。因此，本報告提出 「雙流混合邏輯-結構檢測系統」（Dual-Stream Hybrid Logic-Structural Inspection System, HLSIS）。3.1 系統架構總覽 (System Architecture)系統由三個主要模組構成：骨幹特徵提取器（Backbone Feature Extractor）： 經過領域自適應微調的 DINOv3。結構流（Stream A - Structural）： 基於 SimpleNet 機制的紋理與幾何細節檢測。邏輯流（Stream B - Logical）： 基於 SALAD 機制的組件佈局與語義檢測。這兩個流（Stream）共享同一個骨幹網路以節省推論時間，但在後端分叉處理不同任務。3.2 詳細模組規格3.2.1 模組一：領域自適應骨幹網路 (Domain-Adaptive Backbone)問題： 原生 DINOv3 訓練於自然場景，對 SMT 的金屬反光、阻焊油墨紋理敏感度不足，是導致「騷不到癢處」的主因。解決方案： 利用貴公司擁有的 200 萬張 SMT 集中分佈影像 進行 DINOv3 持續預訓練（Continual Pretraining）。演算法： 使用 DINOv3 的官方自監督學習配方（Masked Image Modeling + DINO Loss）20。數據策略： 無需標註，直接餵入這 200 萬張影像。這將迫使模型學習 SMT 元件的「本質特徵」，如焊點的曲率、IC 引腳的排列規律。蒸餾（Distillation）： 訓練完成的 ViT-Base 或 ViT-Large 模型可能過大。需將其知識蒸餾至輕量級的 ViT-Small 或 ConvNeXt-Small 20，以符合產線推論速度要求。輸出： 多尺度特徵圖（Multi-scale Feature Maps），包含淺層紋理特徵（用於結構流）與深層語義特徵（用於邏輯流）。3.2.2 模組二：結構流 - 微細瑕疵檢測 (Stream A: Structural Defect Detector)核心演算法： SimpleNet (Optimized) 9。設計理由： SimpleNet 在特徵空間合成異常，能產生極其緊緻的決策邊界，對於 0.1mm 等級的微細瑕疵（小瑕疵抓不到的問題）有極高的捕捉率，且不易受背景雜訊干擾。功能規格：特徵適配器（Adapter）： 將 Backbone 輸出的 Patch Token 投影至目標域。異常生成器（Anomaly Generator）： 在訓練階段，對正常特徵加入高斯噪聲 $\epsilon \sim \mathcal{N}(\mu, \sigma^2)$，模擬異常特徵分佈。鑑別器（Discriminator）： 一個簡單的 MLP，用於分類「真實特徵」與「噪聲特徵」。特徵金字塔（Feature Pyramid）： 聚合 Backbone 的第 2 層（高解析度）與第 3 層（語義特徵），確保微小刮痕不被遺漏。3.2.3 模組三：邏輯流 - 特殊邏輯瑕疵檢測 (Stream B: Logical Anomaly Detector)核心演算法： Modified SALAD 5。設計理由： 專門解決缺件、錯件、極性反轉等邏輯問題。功能規格：組件分割頭（Component Segmentation Head）： 接在 Backbone 後端的一個輕量級 U-Net Decoder。偽標籤生成（Pseudo-labeling）： 由於缺乏標註，利用 Segment Anything Model (SAM) 23 對那 10-20 張 OK 照片進行「零樣本分割」，自動生成組件掩碼（Mask）。以此掩碼作為 Ground Truth 訓練分割頭。邏輯鑑別器： 將預測出的組件佈局圖（Composition Map）轉換為描述子（質心座標、面積、長寬比），並與 OK 樣本的統計分佈（如 Mahalanobis Distance）進行比對。判定邏輯： 若某個位置應有電容卻未預測出組件 Mask，或預測出的組件長寬比與標準不符（極性旋轉），即判定為邏輯異常。3.2.4 模組四：生成式數據增強管道 (Generative Data Augmentation Pipeline)問題： 下游任務訓練不穩定，因為缺乏 NG 樣本來定義「什麼是錯誤」。解決方案： 建立 Stable Diffusion (SD) Inpainting 管道 18。Fine-tuning: 使用 LoRA (Low-Rank Adaptation) 24 對 SD 模型進行微調，讓它學會生成 SMT 相關的紋理（焊錫、PCB綠漆）。只需約 50-100 張影像即可訓練一個高品質 LoRA。Prompt Engineering: 設計專屬 Prompt，例如 "solder bridge between pins", "cracked ceramic capacitor", "tombstoning resistor" 26。合成策略： 在 OK 影像上隨機遮罩（Masking）關鍵區域（如引腳間隙），利用 SD Inpainting 生成逼真的連錫或錫珠。用途： 生成 500~1000 張合成 NG 影像，用於訓練 SimpleNet 的鑑別器和驗證模型的收斂性，徹底解決訓練不穩定的問題。4. 產品需求文件 (PRD) 與功能列表 (Feature List)為了讓貴公司團隊能進行內部測試與開發，以下提供詳細的 PRD 與規格表。4.1 產品規格 (Product Specification)規格項目詳細要求驗證指標 (KPI)適用場景SMT AOI (Automated Optical Inspection) & Monitoring)F4.1 骨幹微調 (Backbone Finetuning): 腳本支援載入 2M 數據集進行 DINOv3 增量預訓練。F4.2 早停機制 (Early Stopping): 利用合成 NG 數據集作為驗證集，當對合成瑕疵的檢測率達到高原期時自動停止訓練，防止過擬合。5. 開發規劃與實施路徑 (Development Roadmap)階段一：骨幹網路優化 (Week 1-3)目標： 解決「騷不到癢處」的問題，讓 Backbone 看得懂 SMT。行動：架設 DINOv3 訓練環境 28。清洗 300 萬張工業數據集，剔除極端模糊影像。使用 ViT-Small 或 ViT-Base 進行持續預訓練 (100 Epochs)。驗證： 透過 t-SNE 視覺化，檢查不同封裝類型的元件是否在特徵空間中被更好地區分。階段二：結構流 (SimpleNet) 實作 (Week 4-6)目標： 解決小瑕疵抓不到的問題。行動：基於優化後的 Backbone，實作 SimpleNet 10。調整特徵適配器 (Feature Adapter) 的層數與噪聲參數 $\sigma$。重點： 實作特徵金字塔聚合，將淺層特徵 (Layer 2) 納入計算，以保留高頻細節。階段三：邏輯流 (SALAD) 與合成數據實作 (Week 7-9)目標： 解決邏輯瑕疵與訓練不穩定問題。行動：使用 SAM 自動標註 20 張 OK 影像，產生組件 Mask 23。實作 SALAD 的組件分割頭與邏輯鑑別器 29。搭建 Stable Diffusion + ControlNet 環境，訓練 SMT 專用 LoRA 25。生成 500 張包含連錫、缺件的合成影像，用於聯合訓練。階段四：整合測試與優化 (Week 10-12)目標： 達成 0 漏失與 80% FPY。行動：整合雙流輸出，設計決策融合邏輯（例如：邏輯流由 Rule-based 否決，結構流由 Heatmap 否決）。在內部測試集上進行壓力測試，調整動態閾值演算法。優化程式碼以符合推論速度要求。6. 結論與建議 (Conclusion)貴公司目前面臨的挑戰是典型的「工業 AI 深水區」問題：通用模型在極端數據條件下的失效。解決方案不是修補 FastFlow，而是進行架構升級。透過 DINOv3 的領域自適應預訓練，我們為模型注入了 SMT 的領域知識；透過 SimpleNet，我們利用特徵空間合成解決了小瑕疵的邊界定義問題；透過 SALAD，我們引入了顯式的語義約束來解決邏輯異常；最後，利用 Stable Diffusion 生成的合成數據，我們填補了真實 NG 數據的真空，穩定了訓練過程。此 HLSIS 架構 不僅能滿足當前的 KPI，更具備高度的可擴展性，能適應未來不同產線的檢測需求。7. 附錄：關鍵技術細節與表格表 1: 推薦模型架構比較特性FastFlow (Current)SimpleNet (Recommended Stream A)EfficientAD (Alternative Stream A)SALAD (Recommended Stream B)核心機制正規化流 (Density
