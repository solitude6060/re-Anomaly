# 專案規格：re-Anomaly

## 執行摘要
re-Anomaly 是專為表面貼裝技術 (SMT) 生產線設計的次世代異常檢測系統。針對先前 FastFlow + DINOv3 基準方案的局限性，本專案引入了多骨幹 (Multi-backbone) 與多檢測頭 (Multi-head) 架構，以實現工業級的準確度與性能。系統專注於檢測微細瑕疵以及邏輯/結構性異常，旨在達成極低的漏失率與高推論速度。

## 問題陳述
目前使用 FastFlow 配合 DINOv3 (針對每個腳位建模) 的基準方法面臨以下關鍵挑戰：
- 數據匱乏：每個零件通常僅有 10-20 張 OK 影像，且缺乏用於訓練的 NG (不良) 樣本。
- 微小瑕疵檢測：小型電子零件上的微細瑕疵經常被遺漏。
- 邏輯與結構性異常：系統難以檢測與上下文相關或具有結構性質的異常 (例如：零件雖然外觀正常但位置偏移)。
- 訓練不穩定性：在樣本極少的情況下，模型訓練往往難以收斂或泛化效果差。
- 現有方法局限性：針對每個腳位建模在擴展時計算成本高昂，且缺乏全域上下文資訊。

## 技術目標
- 漏失率 (Miss rate)：0% (零偽陰性)
- 過殺率 (Overkill rate)：低於 10%
- 直通率 (Pass-through rate)：80% 或更高
- 推論延遲：每個感興趣區域 (ROI) 少於 100ms
- 骨幹網路載入時間：少於 500ms
- 下游任務載入時間：少於 100ms

## 解決方案概述
本專案採用多策略實驗方法來處理不同類型的異常：

### 實驗計畫
- **Plan A: PatchCore** - 使用 DINOv2/v3 骨幹搭配 PatchCore 檢測頭 (Memory Bank + kNN)，建立穩定且傳統的異常檢測基準。
- **Plan B: HLSIS** - 結合 DINOv3 與領域自適應預訓練 (DAPT)，以及雙流 SimpleNet + SALAD 檢測頭，專門針對邏輯異常。
- **Plan C: PixIO** - 利用 PixIO-H 骨幹搭配線性/輕量化檢測頭，提升極少樣本情境下的微細瑕疵檢測能力。
- **Plan D: MSFlow** - 採用 PixIO 或 DINOv3 骨幹搭配 MSFlow + HGAD 檢測頭的多尺度方法，實現統一的多類別檢測。

### 多骨幹策略
利用最先進的視覺模型：
- **PixIO**: 增強型 MAE，具備更深的解碼器，並在 200 億張影像上進行預訓練。
- **DINOv3**: 基於 Gram Anchoring 的自監督模型。
- **DINOv2**: 已建立的自監督 ViT 基準模型。

### 領域自適應預訓練 (DAPT)
為了提升工業零件的特徵表示能力，系統將在 300 萬張無標籤工業影像上進行預訓練。

## 系統架構
```text
[ 輸入影像 ]
      |
[ 預處理與 ROI 擷取 ]
      |
[ 特徵提取 (多骨幹) ]
|--- DINOv2 / DINOv3 (基於 ViT)
|--- PixIO-H (增強型 MAE)
      |
[ 檢測頭 (多檢測頭) ]
|--- PatchCore (記憶庫)
|--- MSFlow (正規化流)
|--- SimpleNet / SALAD (雙流)
      |
[ 後處理與異常評分 ]
      |
[ 結果視覺化與 API 回應 ]
```

## 硬體需求
- GPU: NVIDIA RTX 4090 (24GB VRAM)
- 推論運行環境：ONNX Runtime 以實現優化執行。
- 部署：Triton Inference Server 用於可擴展的服務。

## 資料需求
- 預訓練：3,000,000 張無標籤工業影像用於領域自適應。
- 微調/評估：20-30 種不同的 SMT 零件類型，每種零件提供 10-30 張 OK 樣本用於基準設定。

## 成功標準與指標
本專案將根據以下指標進行評估：
- 異常檢測性能：AUROC (ROC 曲線下分) 與 AUPRO。
- 工業指標：漏失率 (P0 優先級)、過殺率與直通率。
- 效率：端到端推論延遲與模型載入時間。
- 穩定性：在樣本有限的情況下，不同零件類型的收斂率與結果變異程度。
