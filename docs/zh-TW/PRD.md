# 產品需求文件 (PRD) - re-Anomaly

## 概述與背景
re-Anomaly 是專為表面貼裝技術 (SMT) 生產線設計的次世代異常檢測系統。在電子製造的高精度環境中，即使是微小的瑕疵也可能導致重大故障。目前的基於規則的檢查系統往往面臨過高的過殺率或遺漏細微瑕疵的問題。re-Anomaly 利用最先進的視覺模型與極少樣本學習 (Few-shot learning) 技術，提供高準確度、即時的檢測方案，能以極少的訓練資料識別結構性與邏輯性異常。

## 目標用戶
* 製造品質保證 (QA) 團隊
* 機器學習 (ML) 工程師

## 功能需求
* **FR1: 極少樣本學習 (Few-shot learning)**: 系統必須支持僅使用 10-200 張 OK 樣本且無需 NG 樣本即可進行訓練，以便快速適配新零件。
* **FR2: 多尺度瑕疵檢測**: 具備檢測從微觀層次的刮痕到巨觀層次的缺件等各種尺度瑕疵的能力。
* **FR3: 基於熱點圖的異常定位**: 提供像素級的異常評分並視覺化為熱點圖，協助 QA 團隊識別瑕疵位置。
* **FR4: 結構性/邏輯性異常檢測**: 除了簡單的表面瑕疵，系統必須能檢測邏輯異常，例如零件方向錯誤或引腳缺失。
* **FR5: ONNX 導出用於部署**: 支持將訓練好的模型導出為 ONNX 格式，以便進行高效的跨平台部署。
* **FR6: Triton 伺服器整合**: 與 NVIDIA Triton Inference Server 整合，實現可擴展且高性能的模型服務。
* **FR7: 可配置的閾值**: 允許用戶調整異常檢測閾值，以根據具體生產需求平衡漏失率與過殺率。

## 非功能需求
* **NFR1: 0% 漏失率**: 強制性要求，確保零偽陰性 (不遺漏任何瑕疵)。
* **NFR2: <10% 過殺率**: 誤判率 (過殺) 必須控制在 10% 以下，以維持生產效率。
* **NFR3: 推論延遲 <100ms**: 每張影像 (200x200 ROI) 的總推論時間必須低於 100ms，以配合即時生產速度。
* **NFR4: 邊緣部署的模型大小限制**: 優化模型架構，以符合生產線邊緣運算裝置的記憶體限制。
* **NFR5: 對影像壓縮失真的魯棒性**: 即使處理具有工業相機常見壓縮失真的影像，系統也必須維持性能。

## 用戶故事
### 製造 QA 團隊
* **作為一名** QA 操作員，**我希望**在檢查影像上看到熱點圖疊加，**以便**我可以快速驗證瑕疵位置。
    * **驗收標準**: 為每個檢測到的異常生成熱點圖，且具備高定位準確度。
* **作為一名** 生產經理，**我希望**確保沒有缺陷的電路板通過工作站，**以便**我們避免昂貴的外場故障。
    * **驗收標準**: 在經過驗證的 NG 影像測試集上達成 0% 漏失率。

### ML 工程師
* **作為一名** ML 工程師，**我希望**將模型導出至 ONNX，**以便**我可以在各種硬體加速器上部署它。
    * **驗收標準**: 模型成功導出至 ONNX，且產生與 PyTorch 實現一致的結果。
* **作為一名** ML 工程師，**我希望**僅使用幾十張 OK 樣本為新零件訓練模型，**以便**我們可以縮短新產品的上市時間。
    * **驗收標準**: 模型僅使用 20 張 OK 訓練樣本即可達成高 AUC。

## 限制與假設
* 輸入影像為 200x200 像素的 ROI 裁切圖。
* 生產線上的照明條件相對穩定。
* 推論硬體環境包括支持 TensorRT/Triton 的 GPU。
* 僅使用 OK 樣本進行訓練 (無監督/自監督方法)。

## 範圍外項目
* 硬體相機整合與觸發邏輯。
* 長期資料儲存與歷史趨勢分析。
* 自動瑕疵分類 (例如將瑕疵分類為「刮痕」或「缺件」)。

## 依賴項
* PyTorch
* Transformers
* ONNX
* Triton
